# 童年回忆 - 响应式卡通视频展示平台 📺

这是一个基于纯原生前端技术栈（Vanilla Web）开发的交互式视频展示网站。

## 🌟 核心
- **动态数据流**：通过 JavaScript 异步（Fetch/XHR）读取本地 JSON 数据，实现无刷新的视频列表与分类渲染。
- **全端响应式**：采用 CSS3 Media Queries 与 Flexbox/Grid 布局，完美适配桌面端与移动端视图。
- **纯粹的前端交互**：不依赖沉重的现代框架，用最原生的 JS 实现了轮播图、分类筛选、页面路由及媒体播放器控制。
- **轻量级部署**：内建 `vercel.json`，支持一键无服务器（Serverless）自动化部署。

## 🛠️ 技术栈
- **UI/UX**: HTML5, CSS3, 原生动画 (Keyframes)
- **逻辑控制**: JavaScript (ES6+), DOM 树操作
- **架构**: 纯前端静态架构 + 模拟 API 数据加载
